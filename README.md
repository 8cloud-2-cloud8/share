# 乐享 · 共同出行记账与分账

一个为 iPhone 竖屏设计的网页 App，核心只有 `index.html` 一个文件，适合 2–10 人旅行、家庭出行或出差共同记账。紫色方框里的大 **S** 使用半透明奶油色缎带层叠，线条从上下两端轻轻延展，整体更圆润柔和，代表 SHARE 和旅行。默认主色是紫色 + 米色。

> 无需安装、没有后端，所有数据保存在当前浏览器的本机存储中。同目录附带了 `manifest.webmanifest`、`sw.js`、`icon.svg`，用于添加到主屏幕和离线缓存。

文件说明：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部界面、样式和逻辑，必需 |
| `manifest.webmanifest` | PWA 名称、图标、竖屏配置 |
| `sw.js` | 离线缓存（HTTPS/localhost 下生效） |
| `icon.svg` | 主屏幕图标 |
| `README.md` | 本说明 |

## 为什么不是 .exe

iPhone 不能运行 Windows 的 `.exe` 程序。要满足「苹果手机端 + 竖屏 + 随手记账」，最合适的形式是网页 App：

- 用 iPhone Safari 打开；
- 点「分享 → 添加到主屏幕」，可以像普通 App 一样全屏打开；
- 页面和数据都在本机，不依赖后台；
- 同一个文件也能在 Windows / Mac 浏览器中打开使用。

如果确实需要 Windows 桌面程序，可以后续再用 Electron 或 Tauri 套壳；但这不会让 iPhone 直接运行 exe。

## 这一版的主界面

项目内不再分「概览 / 账目 / 统计 / 结算」四个页面，而是合并成一个纵向主页面：

1. **顶部摘要**：总支出、人均支出、待转账金额、账目数量；
2. **快速跳转**：总表 / 结算 / 预算；
3. **明细总表**：按大类分组，横向列出「分类 / 时间 / 内容 / 明细 / 金额 / 每位成员 / 备注」。分类图标回到第一列，在该类所有账目里上下居中，图标下加粗写类名。时间显示为 `MMDD` 四位；每个分类的小计行在内容列显示加粗「小计」，小计和合计行都不填灰底。分类之间用加深加粗的细线分隔，表头下的内框线也使用同一宽度和颜色，整表有中粗外框。「合计」「转账」放在内容列下方并加粗，小计/合计金额和转账金额加粗，转账的「应收+ / 应付−」保持普通字重。金额格底色就是暂付款方的颜色，外部/无需分摊不显示底色；成员列头是扁长色块，里面直接写名字首字。**4 人及以内整表在手机竖屏内显示，不横向滚动**；超过 4 人可左右滑动。点任意一行可查看支付清单、完整分摊和备注并编辑；
4. **结算**：只保留「谁转给谁、多少钱」和「是否已结清」，不再展示复杂的成员收支表；
5. **预算对比**：页面最末端的横向条形分析，五大类的实际支出 vs 预估预算，显示偏差百分比。

项目名右侧是加大的「记一笔」按钮，右下角不再放悬浮按钮；顶部右上角是隐藏/显示和项目设置。

## 功能

- **项目管理**：多个旅行/出差项目，独立命名、起止日期、成员、账目和结算记录。
- **人员设置**：2–10 人，名字 + 方形专属底色；色块里自动显示名字首字作为代号，不再单独设置 A/B/C/D；颜色提供清透与莫兰迪两组，也可以自选颜色；已产生账目的成员禁止误删。
- **费用记录**：
  - 日期、暂付款方、五大类、细项、具体明细、金额、备注；
  - 每个大项下的具体细项不再写死，可在「项目设置 → 分类细项」中新增、改名或删除；已用于账目的细项不能直接删除，改名会同步更新已有账目；
  - 交通（机票/高铁/租车/打车/地铁/油费/停车等）；
  - 住宿（酒店/民宿/青旅等）；
  - 景点（门票/讲解/演出/体验等）；
  - 餐饮（正餐/早餐/小吃/咖啡/食材等）；
  - 其他（保险/行李附加/必需购物/签证/通讯/小费等）；
  - 金额支持算式，例如 `120*2+35`、`(80+20)/2`；算式和结果会保存在这笔账里，点开详情仍能看到计算过程，总表只显示最终金额；
  - 暂付款方可以是任一成员，也可以选 **其他**（公费/他人代付/免单）；选其他时总额保留、每位成员应摊为 0、金额格不显示底色；
  - 分摊支持：**均分、按份数、指定金额、个人承担、无需分摊**；
  - 可选择部分成员参与某笔分摊；
  - 可上传当时的支付清单/小票，自动压缩后保存在本机，点总表行或凭证明细查看大图。
- **明细总表**：分类 / 时间 / 内容 / 明细 / 金额 / 成员应摊 / 备注；分类图标固定在第一列并上下居中，类名在图标下加粗；每个分类的小计行在内容列显示加粗「小计」，小计、合计行无灰底，金额及合计/转账行数字加粗，分类之间是加深加粗的细线、整表有中粗外框，表头内框线同宽同色。「合计」「转账」位于内容列下方。金额格用暂付款方底色，外部付款/无需分摊不显示底色。成员列头显示名字首字，不再写 A/B/C/D。4 人以内手机竖屏无需横向拖动。
- **报销限额**：按类别/总支出，设置「每天/全程」「每人/全组」上限；「每人」按每笔实际分摊到各人的金额统计，取最高的一位。超出时项目主页面顶部提醒，详情在项目设置内管理。
- **结算**：
  - 自动计算谁应该转给谁、多少钱，并尽量合并转账；
  - 主页面显示待结清账目、建议转账合计和是否已结清；
  - 复制结算清单；
  - 记录结清，锁定本次账目；新增支出重新累计；
  - 支持撤销最近一次结清。
- **预算对比**：给交通、住宿、景点、餐饮、其他设置预估预算；实际支出以横条显示，竖线表示预算位置，右侧显示超出或低于预算的百分比。
- **外观设置**：四种主题配色、四种背景底色、首页卡片的上方小字/主标题/说明文字，还可以给首页卡片上传自己的背景图。每个主题/背景选项的名称和颜色都可以在「选项内容」里编辑，颜色会自动生成深浅搭配；默认主题为紫色，项目卡下横线和「记一笔」按钮都会跟随主题色。
- **隐私显示**：首页和项目页右上角有眼睛按钮，可一键把项目名、日期、金额和参与人色块/头像显示为 `***` 或隐藏；参与人列头和分摊说明也会隐藏。
- **数据**：自动保存；JSON 全量备份/导入；当前项目 CSV 导出。

## 推荐的人员标识

成员统一使用「**方形底色 + 名字首字**」，例如：

- 林（松林绿）
- 哲（陶土红）
- 雨（海盐蓝）
- 熊（赭黄）

不再单独设置 A/B/C/D。总表列头直接显示为扁长颜色条，里面写名字首字；付款格、选择按钮和首页头像也沿用同一色块。颜色提供清透和莫兰迪两组，可以在新项目或成员设置里自选。

## 使用步骤

1. 新建项目，填写项目名、起止日期、人数和成员名字。需要改大项下的细项时，进入「项目设置 → 分类细项」增减或改名。
2. 每笔花销点项目名右侧「记一笔」：
   - 先选大类和细项；
   - 选实际发生日期；
   - 输入金额（可使用算式，下面会显示计算结果）；
   - 写具体明细（如“车费 1600，高速费 400”）；
   - 选择暂付款方（成员或「其他」）；
   - 选择参与分摊的人，以及分摊方式；可选「无需分摊」；
   - 可填写任意备注；
   - 可拍照/上传支付清单。
3. 在项目主页面看明细总表：分类 / 时间 / 内容 / 明细 / 金额 / 成员 / 备注，分类图标固定第一列并上下居中，类名在图标下加粗；小计、合计行无灰底，金额和转账数字加粗，分类分隔线加深，整表外框中粗。4 人以内全部列直接显示，5 人以上可左右滑动。点任意一行可查看完整算式、支付清单、分摊和备注，并进入编辑。
4. 看下方的结算区，复制清单或记录结清。
5. 页面最下方查看分类预算偏差；需要时点「设置预算」。
6. 出行结束后在「设置与数据」里导出 JSON 备份。

## 自定义外观与文案

首页右上角齿轮 →「设置与数据」→「外观与文案」：

- **主题配色**：梅子紫（默认）/ 松林绿 / 海盐蓝 / 陶土红；
- **背景底色**：米纸 / 雾白 / 暖砂 / 纯白；
- **首页卡片**：可改上方小字、主标题（支持换行）、说明文字；
- **背景图**：从手机相册选一张图，会自动压缩后保存在本机。

主题和文案只影响当前设备。清空浏览器数据会一起清掉。

## 在 iPhone 上打开：为什么需要一个网址

iPhone 的 Safari 不会像电脑那样方便地直接运行本地 HTML 文件；「添加到主屏幕」和离线缓存也需要一个 **HTTPS 网址**。

所谓「静态空间」，可以理解成：**把这几份文件放到一个公开的网盘目录里，它给你一个网页地址**。不需要服务器、不需要数据库、不需要写代码。下面两种方式任选其一。

### 方式 A：Netlify Drop（最快，拖拽上传）

1. 在电脑上新建一个文件夹，例如 `乐享`，把 `index.html`、`manifest.webmanifest`、`sw.js`、`icon.svg` 四个文件放进去。
2. 打开 [Netlify](https://app.netlify.com/)，用邮箱或 GitHub 注册/登录一个免费账号（先登录，之后站点才方便长期保留和管理）。
3. 打开 [Netlify Drop](https://app.netlify.com/drop)。
4. 把整个 `乐享` 文件夹拖到页面的上传区域。等待几秒到一分钟。
5. 页面会给一个类似 `https://xxxxx.netlify.app` 的网址，点开确认能看到「乐享」。
6. 如果站点被设为 private（私有），在站点设置里把访问权限改为 public，否则手机打开会要求登录。
7. 在 iPhone Safari 打开这个网址 → 点底部分享按钮 →「添加到主屏幕」。

以后要更新版本，把新的四个文件放回同一个文件夹，再拖到该 Netlify 项目的部署区域即可。**网址不变，数据就还在。**

### 方式 B：GitHub Pages（免费、公开、稳定）

1. 打开 [GitHub](https://github.com/) 注册/登录免费账号。
2. 点右上角「+」→「New repository」。
3. 仓库名随意，例如 `tongxiang`；选择 **Public**；点「Create repository」。
4. 进入仓库，点「Add file」→「Upload files」。
5. 把 `index.html`、`manifest.webmanifest`、`sw.js`、`icon.svg` 四个文件一起拖进去（确保 `index.html` 在仓库根目录，不要多套一层文件夹），然后点「Commit changes」。
6. 进入仓库的「Settings」→ 左侧「Pages」。
7. 在「Build and deployment」里，Source 选「Deploy from a branch」，Branch 选 `main`、目录选 `/ (root)`，点「Save」。
8. 等 1–3 分钟，刷新 Pages 页面，会显示网址，形如 `https://你的用户名.github.io/tongxiang/`。
9. 用 iPhone Safari 打开这个网址，分享 →「添加到主屏幕」。

GitHub Pages 在国内的访问速度可能不稳定；如果打不开，换 Netlify 或自己的服务器。

### 方式 C：电脑局域网临时预览（只适合测试）

在电脑上进入本文件夹，运行：

```bash
python -m http.server 8000
```

查看电脑的局域网 IP（Windows 可运行 `ipconfig`，找 IPv4 地址），在 iPhone Safari 打开：

```text
http://电脑的局域网IP:8000
```

要求 iPhone 和电脑在同一个 Wi-Fi，并允许防火墙放行 8000 端口。这是 HTTP，不是 HTTPS，PWA 离线缓存通常不会生效，只适合临时试用。关闭命令窗口后服务停止；下次用相同地址和端口打开才能看到同一份数据。

### 方式 D：自己的服务器

如果已经有域名和虚拟主机，把四个文件上传到网站根目录即可，保证访问 `https://你的域名/index.html` 能打开。HTTPS 证书可以在主机面板里一键申请。

### 添加主屏幕后的效果

- 用 Safari 打开网址；
- 点分享按钮（方框向上箭头）；
- 选「添加到主屏幕」；
- 名称可改为「乐享」，点添加；
- 以后从主屏幕图标打开，全屏运行，数据仍保存在这台 iPhone 的 Safari 里。

## 常见问题

**打开后不是最新版？**
PWA 使用网络优先、离线回退。联网时刷新一次即可；如果仍旧，关闭主屏幕 App 再打开。

**手机上打开显示要登录/私有站点？**
Netlify 的站点可能默认私有。去 Netlify 项目设置里把访问权限改为 public；或在登录状态下重新部署并确认可见性。

**换网址后数据不见了？**
数据按网址（域名 + 端口）保存在 Safari 本机。换网址等于换了一份存储。请在旧网址里导出 JSON，再到新网址导入。

**可以直接把 index.html 发到微信里打开吗？**
不建议。微信内置浏览器对本地存储和添加到主屏幕支持差；请用 Safari 打开 HTTPS 网址。

**为什么图标还是旧的？**
iOS 会缓存主屏幕图标。更新紫色 S 图标后，请删除旧的主屏幕图标，再用 Safari 重新「添加到主屏幕」一次。

## 数据与安全

- 无账号、无服务器、无上传；数据只存在当前浏览器的 `localStorage`。
- 清理 Safari 网站数据、换手机、换网址或系统重装都可能丢失数据。
- **重要数据请定期导出 JSON 备份**。
- 本工具只做分账建议，实际转账、报销和票据合规请以你们自己的约定为准。

## 建议自测一次

新建 3 人项目，依次录入：

1. 交通 ¥300，A 付款，3 人均分；
2. 餐饮 ¥120，B 付款，A/B 两人分摊；
3. 购物 ¥50，C 付款，C 个人承担。

主页面摘要应显示总支出 ¥470、人均约 ¥156.67、待转账 ¥140。
结算区建议转账为：B→A ¥40、C→A ¥100。

## 兼容性

- iPhone Safari / iOS 15 及以上（添加到主屏幕、竖屏、安全区适配）。
- 现代 Chrome / Edge / Safari 桌面浏览器。
- 核心页面无外部字体/JS/CSS 依赖；随附 PWA 文件时，网站首次加载后可离线打开（首次加载仍需能访问网址）。
